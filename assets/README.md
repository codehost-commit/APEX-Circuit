# Asset drop zone

This folder is intentionally empty in source control except documentation. Drop free, traceable art here:

- `cars/` — CC0/CC-BY generic/open-wheel models, no real team or sponsor marks.
- `materials/` — ambientCG/Poly Haven PBR texture sets.
- `hdris/` — Poly Haven CC0 HDRIs.
- `audio/` — CC0/CC-BY engine, tyre and ambience sounds.

Record every non-CC0 item in `ATTRIBUTIONS.md`; the game’s credits panel reads that file’s contents during final polish.
